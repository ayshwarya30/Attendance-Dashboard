I developed a Real-Time Attendance Dashboard using PHP, MySQL (phpMyAdmin), and XAMPP (Apache & MySQL) with development support from Claude AI for implementation, debugging and feature development to manage and monitor attendance records for employees across 252 contractor companies. The dashboard consolidated attendance data from over 252 companies and provided an efficient interface for workforce tracking and reporting.

Implemented features including month-wise filtering, custom date-range selection, employee search functionality, and attendance analytics to identify employees who worked more than or less than 25 days. Also enabled company-wise attendance analysis, along with the ability to export company attendance data in CSV and PDF formats for reporting and record - keeping purposes.
